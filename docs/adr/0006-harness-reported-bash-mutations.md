# Harness-reported Bash mutations

Claude Code models now edit files mostly through Bash (inline Python, `sed -i`, heredocs) rather than the Edit and Write tools, so File Mutations built only from write/edit tool targets missed most of their changes. Since Claude Code 2.1.269, each Bash result carries `toolUseResult.bashEditDiff`: the harness's diff of the repository working tree around that command, which the UI renders as the command's diff. Session Index records the files it lists (`changedFiles`, or `files[].filePath` when absent) as File Mutations with `tool='bash'`, keeps them when the command exits non-zero because the change still happened, and adds them to `files_touched` and the Tool Log.

The diff is a net working-tree delta, so it cannot say which part of a command caused which change. Diffs from commands that move the checkout (merge, rebase, pull, cherry-pick, revert, `am`, `reset --hard`, stash, switching or checking out another commit, `gh pr checkout`) would attribute other people's work to the session and are dropped whole, including any edit made in the same command. `shared` diffs, which mix in concurrent agents' changes, and `unavailable` diffs are ignored. Commands whose net effect is invisible to the harness (edits committed or reverted in the same command, gitignored or out-of-repository files) produce no File Mutations.

Mutations are not inferred from command text: without the harness diff there is no ground truth, so Pi and Codex shell commands, and Claude sessions recorded before 2.1.269, keep only their write/edit tool mutations.
